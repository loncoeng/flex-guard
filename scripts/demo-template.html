error — LINE が受け取らない

送信そのものが失敗し、400 が返ります。直さない選択肢がありません。 未知のプロパティ、必須の欠落、10KB / 50KB の超過、アクションの data が 300 文字を超えたとき。

warning — 送信は成功する

LINE は受け取り、配信数も増えます。ただ相手の画面では文字が背景に溶けていたり、画像の場所が空欄になっています。 エラーは返らず、ログにも残りません。反応が無いという形でしか現れないので、運用していても分かりません。

検査しているのは flex-guard のビルド結果そのもので、デモ用の書き直しではありません。 許可プロパティの表は LINE 公開の OpenAPI 定義から生成しています。 MIT
